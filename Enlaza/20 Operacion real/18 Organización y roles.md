## 18. Organización y roles

| Rol | Responsabilidad |
|---|---|
| Consejo o sponsor | Tesis, capital, gobierno y riesgo |
| Dirección | Estrategia, P&L, prioridades y equipo |
| Producto | Problema, experiencia, roadmap y resultados |
| Tecnología | Arquitectura, entrega y confiabilidad |
| Operaciones | Ejecución, calidad, soporte y procesos |
| Marca | Identidad, narrativa y contenidos |
| Comunidad | Participación, confianza y recurrencia |
| Alianzas | Pipeline, contratos y desempeño |
| Comercial | Clientes, ventas y monetización |
| Datos | Instrumentación, análisis y calidad |
| Finanzas | Presupuesto, tesorería y control |
| Legal | Contratos, cumplimiento y riesgos |
| Seguridad | Protección, incidentes y continuidad |

### 18.1 Gobierno de decisiones

Cada decisión material necesita:

- responsable;
- aprobador;
- consultados;
- informados;
- evidencia requerida;
- umbral;
- fecha;
- resultado;
- impacto;
- registro.
