## 15. Tecnología

### 15.1 Arquitectura recomendada

- frontend web responsive o PWA;
- diseño modular;
- backend inicialmente modular;
- API documentada;
- base transaccional;
- almacenamiento de objetos;
- motor de búsqueda;
- CRM;
- capa de comunicaciones;
- analítica;
- integraciones;
- consola interna;
- observabilidad;
- infraestructura como código.

### 15.2 Principio de evolución

Comenzar con un monolito modular cuando sea suficiente. Separar servicios únicamente cuando lo justifiquen:

- escala;
- seguridad;
- resiliencia;
- autonomía;
- límites de dominio;
- cumplimiento;
- velocidad de despliegue.

### 15.3 Build, buy or partner

Evaluar cada capacidad según:

- diferenciación;
- sensibilidad de datos;
- costo total;
- velocidad;
- dependencia;
- integración;
- reversibilidad;
- soporte;
- cumplimiento;
- capacidad interna.
